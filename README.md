# Vector

Notes, config and scripts for my Anki Vector robot, running WireOS (community firmware).

## Setup so far

- Unlocked with the community unlock-prod OTA from https://unlock-prod.skittle.dev/
- WireOS installed from https://websetup.skittle.dev (Custom Firmware stack)

## Useful upstream projects

- [os-vector/wire-os](https://github.com/os-vector/wire-os): WireOS firmware source
- [kercre123/wire-pod](https://github.com/kercre123/wire-pod): self-hosted replacement for Anki's cloud (voice, weather, etc.)
- Vector Python SDK (`wirepod_vector_sdk`)
